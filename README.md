# DropStab Investor Analytics

Парсер и анализатор инвестиционных данных с сайта [dropstab.com](https://dropstab.com/investors).

## Цель проекта

Анализ самых прибыльных крипто-фондов и их инвестиций:

1. **Выбор топ-фондов**: TOP-20 по Retail ROI + TOP-20 по Private ROI (объединённый список ~30-40 уникальных фондов)
2. **Сбор инвестиций**: Все проекты каждого фонда за последние 3 года, которые уже вышли на рынок
3. **Анализ проектов**:
   - Сколько каждый фонд инвестировал в проект
   - Текущая капитализация проекта
   - ROI = капитализация / сумма инвестиций
4. **Проект-центричный вид**: Какие топ-фонды инвестировали в один и тот же проект

**Итоговая цель**: Найти проекты, в которые инвестировали несколько топовых фондов, и оценить их ROI.

## Возможности

- Парсинг ТОП фондов с сортировкой по **Retail ROI** или **Private ROI**
- Сбор всех инвестиций каждого фонда
- Получение детальной информации о проектах (капитализация, раунды)
- **Проект-центричный анализ**: для каждого проекта видно какие фонды инвестировали
- Расчет ROI (капитализация / сумма инвестиций)
- Экспорт в CSV

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Базовый запуск (ТОП-20 по Retail ROI)

```bash
python -m src.main all
```

### Парсинг ТОП-20 по Private ROI

```bash
python -m src.main parse --sort-by private_roi
```

### Расширенный запуск

```bash
# ТОП-30 фондов по Private ROI, инвестиции за 2 года
python -m src.main all --top 30 --sort-by private_roi --years 2

# Только анализ (если данные уже спаршены)
python -m src.main analyze --years 2
```

### Все параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--top, -t` | Количество ТОП фондов | 20 |
| `--years, -y` | Фильтр: инвестиции за N лет | 3 |
| `--sort-by, -s` | Сортировка: `retail_roi` или `private_roi` | `retail_roi` |
| `--fetch-pages, -p` | Страниц для парсинга (20 фондов/стр) | 5 |
| `--data-dir, -d` | Папка для кэша | `data` |
| `--output-dir, -o` | Папка для отчетов | `output` |

## Структура выходных данных

### Проект-центричный вид

```
Проект: Solana
├── a16z: $20M (Series A, июнь 2019)
├── Multicoin Capital: $5M (Seed, март 2018)
├── Jump Trading: $50M (Private Sale, июнь 2021)
├── Текущая капитализация: $77.23B
├── Всего инвестировано: $75M
└── ROI: 1030x
```

### CSV файлы

- `output/projects_analysis.csv` - сводка по проектам
- `output/detailed_investments.csv` - детальная таблица (проект × фонд)

## Структура проекта

```
src/
├── models.py     # Модели данных (Fund, Project, Investment)
├── parser.py     # Парсер сайта dropstab.com
├── storage.py    # Кэширование данных в JSON
├── analyzer.py   # Агрегация и анализ
└── main.py       # CLI интерфейс
```

## Примечания

- Парсер использует задержку 1.5 сек между запросами для rate limiting
- Данные кэшируются в папке `data/` - повторный запуск пропустит уже спаршенные фонды
- Для полного обновления удалите папку `data/`
